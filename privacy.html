Privacy policy

Effective date: 19 November 2026.

structa-rclone is an OAuth client used by a single person, the owner, to run rclone on the owner's own server.

What it accesses

Only the Google Drive scope drive.file: files and folders that this client creates in the owner's Google Drive. It cannot see or change any other file.

What it does with the data

It uploads the owner's own backup files to the owner's Drive, checks them, and deletes backups older than 90 days. Nothing else.

Storage and sharing

The OAuth token is stored only on the owner's server. No data is collected, sold, shared with or transferred to any third party, and none is used for advertising or analytics. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
