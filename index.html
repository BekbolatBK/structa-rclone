structa-rclone

structa-rclone is a private, single-user OAuth client for rclone. It copies the owner's own nightly server backups to the owner's own Google Drive.

It is not a public service: there is no sign-up, and no one other than the owner uses it.

  • Google scope requested: https://www.googleapis.com/auth/drive.file — access only to files this client itself creates.
  • No data is sent to any third party.
